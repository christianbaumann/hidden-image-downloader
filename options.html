18+ content

JoyClub shows 18+ photos only after you enter your password once per session. With your password stored here, the extension enters it in JoyClub's prompt for you: before a profile download and when a JoyClub page loads locked. A wrong password is tried once only.

Risk: the password is stored unencrypted in your Chrome profile. Anyone who can read that profile on disk can read it. The extension types it only into JoyClub's 18+ prompt and never logs it.
